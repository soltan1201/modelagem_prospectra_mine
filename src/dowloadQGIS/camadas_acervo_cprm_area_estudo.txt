 1. DICIONÁRIO DOS TEMAS (o que é cada shapefile e para que serve no projeto)
================================================================================
 lito / litoestratigrafia  Polígonos de unidades geológicas (sigla, nome, idade,
                           litotipos). PRINCIPAL camada: mapear Fm. Salitre /
                           Grupo Una (carbonatos hospedeiros do fosfato), máscara
                           litológica para MaxEnt, rótulo para treino/validação
                           de índices ASTER (carbonato, argilominerais, sílica).
 recmin / recmin_mapa      Pontos de ocorrências e depósitos minerais (substância,
                           status, rocha hospedeira). Fonte de PONTOS DE PRESENÇA
                           de fosfato (filtrar substância = fosfato/apatita/
                           fosforita) e de outros bens para validação.
 recmin_historico_mapa     Ocorrências minerais históricas/garimpos.
 estrutura / estrut        Linhas: falhas, fraturas, dobras, lineamentos, contatos.
                           Variável de distância a estruturas (controle de
                           mineralização) para o MaxEnt.
 medida_estrutural/foliacao Pontos com atitudes (direção/mergulho). Pouco uso
                           direto no modelo; útil para interpretação.
 afloramento               Pontos de estações de campo com descrição de rocha.
                           Verdade de campo para validar classificação ASTER.
 geocronologia             Pontos com idades radiométricas. Interpretação apenas.
 perfil_geologico          Linhas de seções geológicas. Interpretação apenas.
 dique / veio_quartzo      Linhas/pontos de diques e veios. Secundário.
 geodiv (geodiversidade)   Unidades geológico-ambientais simplificadas (relevo,
                           solo, aquífero). Contexto; menos detalhe que "lito".
 bifilar/unifilar/drenagem Hidrografia. Útil para máscara/água e geoquímica
                           de sedimento de corrente; não é prioridade.
 euler / linmag / gt_2sigma (Cartas de Anomalias) Soluções de Euler (fontes
                           magnéticas, profundidade), lineamentos magnéticos,
                           anomalias do gradiente total > 2 desvios. Estruturas
                           profundas para o modelo.
 *.tif aerogeofísica       Gamaespectrometria: K(%), eTh, eU, razões (U/K, Th/K,
                           U/Th), contagem total, ternário RGB; magnetometria:
                           campo anômalo (mag/cma), 1ª derivada vertical (1dv/dz),
                           sinal analítico (sinal/isa), gradiente total (gt).
                           eU e razões U/Th, U/K são proxy clássico de fosforito
                           (apatita concentra urânio) => covariáveis para MaxEnt.
 geologia_preditivo.tif    Mapa geológico preditivo gerado a partir da geofísica.
 *.xyz (Geosoft)           Dados brutos de linhas de voo. Só servem para
                           regridar no Oasis Montaj/Python; os .tif já são os
                           grids prontos. => [C] salvo necessidade específica.
 geoquímica .xlsx          Análises de rocha, solo, sedimento de corrente,
                           concentrado de bateia (P2O5 quando analisado).
                           Pontos de presença/ausência e validação.
